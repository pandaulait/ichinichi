# Stock

## 概要
タイムラインに未配置のタスクを保管するエリア。タスクの入口・出口として機能する。

## ビジネスルール
- ストック内タスクは時刻情報を持たない（`start`/`end` なし）
- ストックからドラッグしてタイムラインへ配置すると Task ドメインに移行する
- タスクを×ボタンで削除するとストックへ戻る（削除ではない）
- ストック内でのタスク順序に特別な制約は<!-- 要確認: 順序保証の有無 -->

## 操作と権限
- ユーザーはテキスト入力で新規タスクをストックに追加できる
- ストックからタイムラインへドラッグ配置できる
