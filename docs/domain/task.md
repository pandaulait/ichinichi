# Task

## 概要
タイムラインに配置された時刻付きタスク。列・開始・終了時刻を持ち、ドラッグで操作できる。

## 状態・ライフサイクル
- ストック（未配置）→ タイムライン（配置済み）→ ストック（復帰）
- ストックにある間は `start`/`end` を持たない

## ビジネスルール
- 時刻は 3:00（180分）〜 27:00（1620分）の範囲内のみ有効
- スナップ単位は 15分固定。端数は切り捨て
- 同じ列で時間が重なるタスクは副列に自動で振り分けられる（列内衝突時）
- 最小継続時間は<!-- 要確認: コード上の制約未確認 -->

## 操作と権限
- ユーザーはドラッグで移動・リサイズ可能
- 30m / 60m / 90m ボタンで継続時間を即座に変更可能
- ×ボタンでタイムラインからストックへ戻せる
