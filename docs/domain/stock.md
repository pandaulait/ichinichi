# Stock

## 概要
タイムラインに未配置のタスクを保管するエリア。タスクの入口・出口として機能する。
複数のグループに分けて管理でき、グループごとに名前と色を設定できる。

## ビジネスルール
- ストック内タスクは時刻情報を持たない（`start`/`end` なし）
- ストックからドラッグしてタイムラインへ配置すると Task ドメインに移行する
- タスクを×ボタンで削除するとストックへ戻る（削除ではない）
- ストック内でのタスク順序に特別な制約はない
- ストックはグループ（`stockGroups`）で管理される。各アイテムは `groupId` で所属グループを持つ
- グループを削除すると、所属タスクは残存グループのいずれかに自動移動する（消えない）
- グループは1つ以上必須（1つのときは削除不可）
- タイムライン上のタスクも `groupId` を持ち、グループ色が背景色として反映される

## 操作と権限
- ユーザーはテキスト入力でグループを指定して新規タスクをストックに追加できる
- ストックからタイムラインへドラッグ配置できる
- グループの追加・削除・名前変更・色変更ができる
