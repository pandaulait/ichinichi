# ドキュメントインデックス

> このインデックスは調査の地図です。
> 正確性は保証されません。必ず実コードで確認してください。

## 使い方（Claude へ）
1. 該当するドメインまたは機能のファイルを Read ツールで開く
2. 「調査起点」に書かれたファイルを実際に読んで確認する
3. インデックスと実装に食い違いがあれば作業前に報告する
