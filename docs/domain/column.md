# Column（列）

## 概要
タイムラインを縦に分割する並行ストリーム。複数のタスク系列を同時に表示するための単位。

## ビジネスルール
- 列は動的に追加・削除できる（デフォルト3列）
- 列幅はマウスドラッグで個別にリサイズ可能
- 列を削除すると<!-- 要確認: その列のタスクがどうなるか未確認 -->
- 各タスクは特定の列に属し、列間ドラッグで移動できる

## 操作と権限
- ユーザーは＋ボタンで列を追加、×ボタンで削除できる
- 列区切りのディバイダーをドラッグして幅を変更できる
